- GolfDirecto Parejas uses its own edge function `parse-golfdirecto-pairs` (api/v2/public) + adapter `golfDirectoPairsToParsedPairs` feeding the Excel pairs flow; never shared with the individual `parse-results` parser — isolates regressions.
- Player identity is `players.id`; `players.license` is nullable only when `license_exempt = true` (explicit admin confirmation in the pairs importer). Pairs are resolved by their two player ids first; `pair_key` uses `ID:<players.id>` for unlicensed players. Never invent licenses — keeps federative data real and prevents duplicates when a license is added later. A source row without license may be linked (explicit admin choice, `fairwayPlayerId`) to ANY existing player, licensed or exempt; the linked player is reused as-is — prevents duplicates like the J5 Barros case.
- Promotions (`promotions` table, fixed field names read by panoramicaclubdegolf.com) store full public URLs in bucket `photos/promotions/`; `purge-promotion-images` (cron 02,03 UTC, runs only at 04:00 Madrid) nulls images 15 days after end_date — external site contract, DST-safe.
- Promotion click tracking: public `track-promotion-click` (GET ?id= logs + 302 to CTA; POST beacon); counts via admin-only RPC `get_promotion_click_counts` — external site can't write tables directly.
